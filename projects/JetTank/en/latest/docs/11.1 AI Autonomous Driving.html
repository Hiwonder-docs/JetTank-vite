11.1.1.1 Introduction to Programming Software--WonderCode ​

WonderCode is a Scratch programming software designed for CoreX controller. It supports coding with graphical blocks and converting Python code automatically.

11.1.1.2 Install WonderCode ​

  1. Find the installation package in the folder “WonderCode Installation Package”.
  1. Select the language to to be used, and the click OK.
  1. Select the folder where the software is installed and you can remain the default settings. Then click “Next”.
  1. Then finish the installation following the given pictures.
  1. After installation, you can find it on your computer desktop.

11.1.1.3 Connect to Device ​

  1. Connect a CoreX controller to a computer through USB cable.
  1. Double-click WoderCode software to open it.
  1. Firstly, click at lower left corner to add an extension. Click “Controller -> CoreX” in sequence.
  1. Click “Connect device” and select the corresponding port.

NOTE

the port to be connected is not fixed, and you need to connect to the corresponding port based on your computer. “COM1” is generally communication port, so please DO NOT connect to it.

  1. When the device matches with the software successfully, the below pop-up will appear.

11.1.1.4 Download Programs Onto Controller ​

  1. After the device is connected to the software successfully, and then click-on “UploadMode”.
  1. Then directly drag the program files to the home interface. Or you can click-on “File -> Load files from your computer” to upload the programs. NOTE: the related programs can be found in the same folder.
  1. Then click-on “Upload” to start downloading the programs onto CoreX.
  1. Once the download is completed, the below pop-up will appear to inform of you.

11.1.1.5 Program Outcome ​

After the programs are downloaded successfully, disconnect the CoreX with the computer. Then connect LED module to No.8 port of controller using 4PIN wire, and turn on the switch on the controller. LED module will cycle between red and green ever 10 seconds.

  1. After CoreX boots up successfully, red light is lit for 10 seconds first.
  1. In 10 seconds, the LED module will turn green. Then it changes red after 10s. This cycle will continue indefinitely.

Calibrating the position information of the yellow line relative to the image.

python
def get_max_y(self, image):
    h, w = image.shape[:2]
    roi = image[:, int(w/2):w]
    flip_binary = cv2.flip(roi, 0)
    max_y = cv2.minMaxLoc(flip_binary)[-1][1]
    return h - max_y

Obtain the height and width of the image. Divide the width by two and use this value to crop the image. After cropping, flip the image. Finally, calculate the difference in height of the yellow line in the image. Subtract this difference from the original video frame's height to obtain the offset of the yellow line.

python
def get_max_x(self, image):
    h, w = image.shape[:2]
    roi = image[int(h/2):h, 0:int(w/2)]
    flip_binary = cv2.flip(roi, 1)
    (x, y) = cv2.minMaxLoc(flip_binary)[-1]
    return 320 - x, y + 240

Modify the travel path based on the current offset value.

Applying dilation and erosion processing to image to make a smoother image, aiming to find target contour in the subsequent operations.

The erode() function is used to perform an erosion operation on image. The meanings of the parameters inside the parentheses are as follows:

The first parameter “mask” is the input image.

The second parameter “cv2.getStructuringElement(cv2.MORPH_RECT, (3, 3))” determines the nature of the operation through a structuring element or kernel. The first argument inside the parentheses specifies the shape of the kernel and the second argument specifies the size of the kernel.

The dilate() function is used to perform a dilation operation on image. The meanings of the parameters inside the paraphrases is the same as the erode() function.

def plot_one_box(x, img, color=None, label=None, line_thickness=None):
    tl = (
        line_thickness or round(0.002 * (img.shape[0] + img.shape[1]) / 2) + 1
    )

    c1, c2 = (int(x[0]), int(x[1])), (int(x[2]), int(x[3]))

11.1.7.4 Function Performance ​

Lane keeping

After starting the game, place the robot on the road of the map. Then it will recognize the yellow lines. It will move forward if the yellow lines are straight, or turn to stay in the lane if the yellow lines are curved.

Traffic light recognition

When it is red light, JetAuto will stop. When it is green light, it will keep going. Once it detects the zebra crossing, it will slow down and go forward.

Turning Traffic Sign and Parking Sign Recognition

When recognizing turning right traffic sign, it will turn right then keep going forward. When recognizing parking traffic sign, it will parallel park.

NOTE

JetTank will perform the above actions in in a continuous cycle.

  • Image Processing

Converting the image into LAB space. The cv2.cvtColor() function is color space conversion function.

python
img_lab = cv2.cvtColor(image, cv2.COLOR_RGB2LAB)  # rgb转lab

The first parameter “image” is the input image.

The second parameter “cv2.COLOR_BGR2LAB” is used for format conversion. “cv2.COLOR_BGR2LAB” is used to convert from the BGR format to the LAB format. If you need to convert to RGB from LAB, “cv2.COLOR_BGR2RGB” can be used.

Gaussian Blur

Using the GaussianBlur() function from the cv2 library to perform Gaussian filtering operation on image, aiming to eliminate noise present in the image.

python
img_blur = cv2.GaussianBlur(img_lab, (3, 3), 3)  # 高斯模糊去噪

The first parameter “img_lab” is the input image.

The second image “(3.3)” represents the size of the Gaussian convolution kernel. The height and width of the kernel must both be positive and odd numbers.

The third parameter “3” is the standard deviation of the Gaussian kernel in the horizontal direction.

Binarization

The inRange() function is employed to apply binarization to image.

python
mask = cv2.inRange(img_blur, tuple(lab_data['lab']['Stereo'][self.target_color]['min']), tuple(lab_data['lab']['Stereo'][self.target_color]['max']))  # 二值化

The first parameter “img_blur” is the input image.

The second parameter “tuple(lab_data['lab'][self.target_color]['min'])” indicates the minimum value of the color threshold.

The third parameter “tuple(lab_data['lab'][self.target_color]['max'])” indicates the maximum value of the color threshold.

When the RGB value of a certain pixel falls within the range of color threshold, that point will be assigned as a value of “1”. Otherwise, it is assigned a value of “0”.

Dilation and Erosion Operation

Applying dilation and erosion processing to image to make a smoother image, aiming to find target contour in the subsequent operations.

python
eroded = cv2.erode(mask, cv2.getStructuringElement(cv2.MORPH_RECT, (3, 3)))  # 腐蚀
dilated = cv2.dilate(eroded, cv2.getStructuringElement(cv2.MORPH_RECT, (3, 3)))  # 膨胀

The erode() function is used to perform an erosion operation on image. The meanings of the parameters inside the parentheses are as follows:

The first parameter “mask” is the input image.

The second parameter “cv2.getStructuringElement(cv2.MORPH_RECT, (3, 3))” determines the nature of the operation through a structuring element or kernel. The first argument inside the parentheses specifies the shape of the kernel and the second argument specifies the size of the kernel.

The dilate() function is used to perform a dilation operation on image. The meanings of the parameters inside the paraphrases is the same as the erode() function.

Extract ROI Area

Extracting regions from an image allows for subsequent image comparison and analysis.

python
blob = image[roi[0]:roi[1], roi[2]:roi[3]]  # 截取roi

The blob() function is used to extract the ROI area. The meanings of the parameters inside the parentheses is as follow:

The first parameter “roi[0]:roi[1]” represents the minimum and maximum x-axis values for the ROI region that the camera captures from the image.

The second parameter “roi[2]:roi[3]” represents the minimum and maximum y-axis values for the ROI region that the camera captures from the image.

def get_max_y(self, image):
    h, w = image.shape[:2]
    roi = image[:, int(w/2):w]
    flip_binary = cv2.flip(roi, 0)
    max_y = cv2.minMaxLoc(flip_binary)[-1][1]
    return h - max_y

def get_object_callback(self, msg):
    objects = msg.objects
    if objects == []:
        self.red = False
        self.green = False
        self.right_area = -1
        self.park_x = -1
        self.center = None
        self.min_distance = 0
    else:
        min_distance = 0
        for i in objects:
            class_name = i.class_name
            self.center = (int((i.box[0] + i.box[2])/2), int((i.box[1] + i.box[3])/2))
            if class_name == 'right':
                self.right_area = abs((i.box[0] - i.box[2])*(i.box[1] - i.box[3]))
            if class_name == 'crosswalk':
                if self.center[1] > min_distance:
                    min_distance = self.center[1]
            if class_name == 'park':
                self.park_pos = self.center
            if class_name == 'red':
                self.red = True
                self.count_red = 0
            else:
                self.count_red += 1
            if self.count_red == 2:
                self.count_red = 0
                self.red = False

            if class_name == 'green':
                self.green = True
                self.count_green = 0
            else:
                self.count_green += 1
            if self.count_green == 2:
                self.count_green = 0
                self.green = False

        self.min_distance = min_distance

def park_action(self):
    twist = geo_msg.Twist()
    twist.linear.x = 0.15
    self.mecanum_pub.publish(twist)
    rospy.sleep(0.25/0.15)
    self.mecanum_pub.publish(geo_msg.Twist())
    rospy.sleep(0.2)

    twist = geo_msg.Twist()
    twist.angular.z = -1
    self.mecanum_pub.publish(twist)
    rospy.sleep(math.pi/2/1)

    twist = geo_msg.Twist()
    twist.linear.x = 0.15
    self.mecanum_pub.publish(twist)
    rospy.sleep(0.4/0.15)

    twist = geo_msg.Twist()
    twist.angular.z = 1
    self.mecanum_pub.publish(twist)
    rospy.sleep(math.pi/2/1)
    self.mecanum_pub.publish(geo_msg.Twist())
