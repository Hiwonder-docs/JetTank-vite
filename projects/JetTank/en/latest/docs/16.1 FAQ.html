16.1 FAQ ​

16.1.1 FAQ ​

Q1: Why does the robot not work after turning on power switch?

A1: Check whether battery wire is connected. For shipping safety, battery wire is disconnected. Before charging and operating robot, you need to connect battery wire following the instructions in “1. Basic Lesson -> Lesson 2 Device Charging”.

Q2: Why can Android app connect to robot Wi-Fi, but cannot search for the robot?

A2: 1. Check whether all necessary permissions are granted to the app.

2. Ensure mobile data is turned off, and location service is turned on.

3. Reconnect to the device WiFi, then return to app. Tap to refresh.

Q3: Why can’t 7-inch LCD screen support touch control?

A3: Check whether the power cable of screen is connected to “CTOUCH” port. Only when it is connected to “CTOUCH” port, screen supports touch control.

Q4: Why there is no live camera feed on the app?

A4: Accidental touching while operating the robot may cause the camera cable to become loose, resulting in no live camera feed on the app. Please ensure that the camera cable is securely connected or try re-plugging it before using the robot.

Q5: Why does the buzzer on the robot emit a "beep" sound after the robot has been working for a while?

A5: The robot has low-voltage alarm. When the voltage drops below 10V, its buzzer will emit a “beep” to remind you of charging the robot.

Q6: Why the robot might not perform well in object tracking or line following tasks?

  • A6

1. The size of the color picking circle should be set appropriately. If it is too large, it may mistakenly select the color of objects other than the target. Conversely, if it is too small, it may not capture the color of the target accurately.

2. It is important to ensure that there are no objects with colors similar to the target object around.

3. When experiencing the object tracking game, it is recommended to move the object on the ground to allow the robot to track it more effectively.

Q7: Why can't we control the robot through the app or wireless handle?

A7: Please confirm that the installation and connectivity of app are correct and that the handle receiver is properly inserted into the robot. Additionally, you will need to enable the app auto-start service by referring to the PDF file provided in “7. Motion Control Lesson->1. Basic Control Lesson->Lesson 9 Handle Control”. This service includes the handle control function, so it is important to ensure that it is properly enabled.

Q8: How can we resolve the issue of the computer being unable to detect the robot's hotspot after disabling "Enable Wi-Fi" on the robot's system desktop?

  • A8

1. Connect Jetson Nano and computer through USB cable.

2. Access the robot system desktop using the fixed IP by following the instructions accessible in “7. Motion Control Lesson->1. Basic Control Lesson->Lesson 1 Set Development Environment”.

3. Refresh the Wi-Fi list on both your phone and computer to check whether the robot’s Wi-Fi is available.

Q9: How can we enable the robot to connect to the external internet?

A9: To allow the robot to access the external internet, you will need to configure the robot to STA LAN mode. Please refer to “1. Basic Lesson->Lesson 6 App Connection” for detailed instruction.
