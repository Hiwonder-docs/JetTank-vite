  3. Connect through USB port: connect Jetson Nano board to your computer through USB cable, and then use static IP to connect. (no internet connection)

  • AP Direct Connection/STA LAN Mode
  1. JetTank will enter AP direct connection mode by default after booting up, and it will generate a WiFi starting with “HW”. Connect your computer to this WiFi.

  1. Next, modify the name in “Name” box to “JetTank”, and other options remain unchanged. Then click “Connect”.
  1. Next, input the username and password. Username is “hiwonder” and password is “hiwonder”. And you can tick “Save this password” for next quick login. Click “Login” button. Then you will successfully access to Jetson Nano desktop.
  1. Note: If robot is configured as STA LAN mode, you can follow the same operation steps but need to change the corresponding IP, Username and password in steps 2,3 and 4.
  • Connect through USB Port

If you are using desktop computer, you can use NDIS compatible device for fluent running. Use the static IP “192.168.55.1” and follow the following steps to operate:

  1. Connect JetTank to your computer through Micro USB cable.
  1. Right click “This Computer” and then select “Manage”.
  1. Next, click “Device Manager-> Remote adapters->Remote NDIS Compatible Device” in sequence. Then right click “Remote NDIS Compatible Device” to update driver.
  1. After the driver is installed, login the system according to the instruction in “2.2 Device Connection”. And the IP address is changed to “192.168.55.1”.

7.1.3 Working Logic of Tracked Chassis ​

7.1.3.1 Track Construction ​

The track is driven by the front driver wheel, which is a flexible chain surrounded by front drive wheel, return rollers, rear drive wheel, and road wheels.

The track consists of track plates, track pins, etc.

The tracks pins connect all the track plates together to construct the track chain. The track plates have holes at both ends to engage with the front drive wheel, and rear drive wheel in the middle to regularize the tracks and prevent them from falling off when the tank is turning or moving sideways. There are reinforced anti-skid bars on the side in contact with the ground to improve the sturdiness of the track plates and the adhesion of the tracks to the ground.

  • Front Drive Wheel

Provide the main driving force to drive car to move. It is usually assembled on the rear of tracked car .

  • Road Wheel

Carry the weight of the tank car and regularize the tracks. It can evenly distribute the track pressure on the ground to improve the smoothness of movement

  • Rear Drive Wheel

Its position depends on the position of the rear drive wheel mostly installed in front of the car. It is mainly used to make the car move in a correct direction, which can prevent runaway and overtracking.

  • Return Roller

It is used to hold the track and prevent it from sagging and slipping sideways. To reduce the vibration and jump of the track during the movement.

7.1.3.2 Tracked Chassis ​

JetTank uses tracks for movement. When the tracked chassis travels, it is like walking on a paved track. The power launched by the tracks is continuously transmitted from the front drive wheel, which then continuously drive the tracks to move.

Tracked chassis has stronger ability to cross obstacles and ditches, smooth movement and not easy to skid, strong climbing ability and not easy to tip over, strong load capacity and not easy to fall into soft ground.

However, due to the high sliding steering resistance, the steering is slow. Because the contact surface between the tracks and the ground is larger, the resistance to be overcome during sliding steering is also larger than that of wheeled robots.

7.1.3.3 Motion Analysis ​

Tracked chassis uses two encoder motor as driving force, which are motor A and motor B. The encoder motor can control the motor speed accurately with the encoders.

  • Move Forward and Backward

Suppose with same direction. When the tracked car moves forward, the motors are set to rotate forward and the tracks are subjected to the friction force of the ground forward. Since the motor rotation speed is the same, the tracks on the left and right sides are subjected to the same friction force, and the tracked car will move forward in a straight line.

  • Turning

When turning, the tracked car needs to cut off the power to one side of the track and brake the track to make it stationary, and rely on the other side of the track to push to make the turn, such as turning left and letting the rear track turn forward, or letting both tracks move forward and backward at the same time to achieve in-situ turning.

7.1.4 Omnidirectional Movement Control ​

7.1.4.1 Project Logic ​

Through controlling the front drive wheel moving forward or backward, the tracked car can be control to in all directions.

Through the motion control node, hiwonder_controller, the program publishes the message about the set linear velocity and angular velocity. Then analyze the linear velocity and angular velocity to control the motors to rotate so as to make JetTank move toward the corresponding direction.

The source code of this program is stored in:

/home/ros_ws/src/hiwonder_driver/hiwonder_controller/scripts/hiwonder_controller_main.py

rospy.Subscriber('hiwonder_controller/cmd_vel', Twist, self.cmd_vel_callback)
self.go_factor = rospy.get_param('~go_factor', 1.00)
self.turn_factor = rospy.get_param('~turn_factor', 1.00)
python
linear_x = self.go_factor * msg.linear.x
angular_z = self.turn_factor * msg.angular.z
self.mecanum.set_velocity(speed, direction, angular_z, speed_up=speed_up)

7.1.4.4 Program Analysis ​

Subscribe to Motion Control Node

Subscribe to the topic published by jetauto_controller node to acquire the related motion data.

python
rospy.Subscriber('hiwonder_controller/cmd_vel', Twist, self.cmd_vel_callback)
rospy.Subscriber('cmd_vel', Twist, self.app_cmd_vel_callback)

Load Parameters

Load the linear velocity and angular velocity parameters

python
self.go_factor = rospy.get_param('~go_factor', 1.00)
self.turn_factor = rospy.get_param('~turn_factor', 1.00)
python
def cmd_vel_callback(self, msg):
    linear_x = self.go_factor * msg.linear.x
    linear_y = self.go_factor * msg.linear.y
    angular_z = self.turn_factor * msg.angular.z

Among them, only x and y value are required for linear velocity. With the robot as the first person view, positive X-axis direction is the front of the robot, and Y-axis direction is its left side. The unit of linear velocity is m/s and its linear velocity ranges from -0.7 to 0.7 m/s.

Only z value is required for angular velocity. When Z value is positive number, JetTank will rotate counterclockwise. When Z value is negative number, the robot will rotate clockwise. The unit is rad/s and its angular velocity ranges from -3.5 to 3.5 rad/s.

Control Motor

Analyze and calculate the linear velocity and angular velocity to get the parameter required by the motor to rotate. Then control the motor to rotate with set_velocity function to let the robot move.

python
linear_x_, linear_y_ = linear_x * 1000.0, linear_y * 1000.0  # mm to m
speed = math.sqrt(linear_x_ ** 2 + linear_y_ ** 2)
direction = math.atan2(linear_y_, linear_x_)
direction = math.pi * 2 + direction if direction < 0 else direction
self.mecanum.set_velocity(speed, direction, angular_z, speed_up=speed_up)

The meaning of the parameters are as follow.

The first parameter “speed” refers to the motor speed ranging from -100 mm/s to 100 mm/s. When the value is negative number, motor will rotate counterclockwise.

The second parameter “direction” refers to the moving direction of robot ranging from 0 to 360 degree. When it is set as 90°, it will move forward. When it is set as 270°，it will move backward. When it is set as 0°, it will move right. When it is set as 180°, it will move left.

The third parameter “angular_z” is offset rate whose unit is 5 rad/s and ranges from -2 to 2. When it is set as positive number, the car will move counterclockwise. When it is negative number, it will move clockwise.

The fourth parameter “speed_up” is used to increase the time required for acceleration and slow down the process of increasing speed when the speed increases rapidly.

7.1.6 Introduction to PID Algorithm ​

7.1.6.1 PID Algorithm Description ​

PID algorithm is the most widely used autonomous controller which controls a process according to the ratio of errors, Proportional (P), Integral (I), and Derivative (D). With simple logic, it is easy to realize and can be widely applicable. And its control parameters are separate and it is easy to select the parameter.

Simplify:

And:

u(t)——the output of the PID controller；

Kp——ratio factor；

Ki——integral time constant；

Kd——derivative time constant；

e(t)——the difference between the given value and the measured value (error)

7.1.6.2 PID Algorithm Logic ​

In a closed-loop control system, the output result of the object controlled will be returned to affect the output of the controller so as to generate one or multiple loop. The closed-loop system has positive and negative feedback. If the feedback signal is opposite to the given signal, it is negative feedback. If they are the same, it is positive feedback.

  • Proportional

Error is the difference between the given value (the set threshold r(t) ) and the measured output (c(t)). After the proportional is introduced, the output of the system is proportional to the error, which can reduce the error quickly and stabilize the system. When the system tends to stabilize, steady-state error will still exist and cannot be eliminated. The control effect of proportional depends on the value of Kp. The smaller the proportional coefficient Kp, the weaker the control and the slower the system response. On the contrary, the larger the proportional coefficient Kp, the stronger the control, and the faster the system response. However, too large Kp will cause the system to generate large overshoot and oscillation. The advantage of proportional control lies in its fast response, but the disadvantage is that there is a steady-state error.

Take a bucket for example. There is a hole at the bottom of the bucket, but you need to maintain the water in the bucket at 1m. And the current water level is 0.2m, and the water will leak 0.1m whenever you add the water. Here, proportional control can be adopted to control the water volume. The current water volume is 0.2m and the target is 1m. Set Kp=0.4. Then u= 0.4*e, and e = last water volume - current water volume

The first error: e(1)=1-0.2=0.8m. Therefore, the volume of the added water is 0.32m (Kp*0.8= 0.4*0.8 = 0.32m), and the current water volume in the bucket is 0.42m (0.2+0.32 -0.1=0.42m)

The second error: e(2) = 1-(0.2+0.32) =0.48m. Therefore, the volume of the added water is 0.192m (Kp*0.48=0.192m), and the current water volume in the bucket is 0.552m (0.52+0.192=0.552)

Lastly, the water level stabilizes at 0.75m, and the error is 0.25m. When you add 0.1m water, the volume of the water added is equivalent to the volume of the water leaking. And this kind of error is called steady-state error.

Steady-state error is defined as the difference between the output under the system tends to stabilize and the target output.

  • Integral

Integral aims at eliminating the steady-state error. The integral of the error over time is continuously accumulated to keep the output changing so as to reduce the error. If the integral time is sufficient, the steady-state error can be completely eliminated. The smaller Ti is, the stronger the function of integral is. But too strong integral function will make the system overshoot and even oscillate. The advantage of the integral is that the steady-state error can be completely eliminated, but the disadvantage is that the response speed is reduced and the overshoot will be too large.

In the example given in “2.1 Proportional”, the steady-state error still exists after proportional control is adopted. To eliminate it completely, you can add integral control, and set the integral constant Ki as 0.3 (Ki=0.3).

The first error: e(1)=1-0.2=0.8m. Therefore, the volume of the added water is: Kp*0.8= 0.4*0.8 = 0.32m, KI * e(1) = 0.3 * 0.8 = 0.24, and and the final added water is: 0.32m + 0.256 = 0.56. And the current water volume in the bucket is : 0.2+ 0.276 - 0.1=0.66

The second error: e(2)=1-0.66=0.34m. Therefore, the volume of the added water is: Kp*0.34 = 0.4*0.34 = 0.136m, KI * (e(2)+e(1)) = 0.3 * 0.342 = 0.342, and the final added water is: 0.136m + 0.342 = 0.478. And the current water volume in the bucket is : 0.66+ 0.478 - 0.1=1.038

After the Integral control is adopted, the steady-state error is completely eliminated, but overshoot occurs.

  • Derivative

The slope error can be obtained by differentiating the error, and the slope reflects the change (rate of change) of the error signal, so the error can be adjusted in advance in derivative part. And it takes effect at the moment when the error appears or changes, so as to avoid excessive overshoot and reduce the dynamic error and response time. The larger the derivative coefficient Td, the stronger the ability to suppress the error variation. The advantage of derivative is that it suppress overshoot and speed up the response. The disadvantage is that the anti-interference ability is poor. When the interference signal is strong, it is not recommended to add derivative.

In the above example, the integral effectively eliminates the steady-state error, but overshoot occurs. In order to reduce the overshoot, a derivative control is added. Set Kd as 0.3 (Kd=0.3).

The first error: e(1)=1-0.2=0.8m. Therefore, the volume of the added water is: Kp*0.8 = 0.4*0.8 = 0.32m, KI * e(1) = 0.3 * 0.8 = 0.24. And KD = 0 (because the current water difference is 0.8). The final added water is: 0.32m + 0.256 = 0.56. And the current water volume in the bucket is : 0.2+ 0.276 - 0.1=0.66

The second error: e(2)=1-0.66=0.34m. Therefore, the volume of the added water is: Kp*0.34 = 0.4*0.34 = 0.136m, KI * (e(2)+e(1)) = 0.3 * 0.342 = 0.342. And KD*（e(2) - e(1)）= 0.3*(0.342 - 0.8) = -0.138. The final added water is: 0.136m + 0.342 -0.138 = 0.34. And the current water volume in the bucket is : 0.66+ 0.478 - 0.1=0.9

Compared with proportional control, the overshoot is weakened.

self.joy_sub = rospy.Subscriber('joy', sensor_msg.Joy, self.joy_callback)

Drive the Motor to Move

Convert the acquired handle control message into the linear velocity and angular velocity in the corresponding direction. Then publish the topic through the underlying driver node to push the motor to rotate

python
def axes_callback(self, axes):
    twist = geo_msg.Twist()
    twist.linear.y = 0
    twist.linear.x = misc.val_map(axes['ly'], -1, 1, -self.max_linear, self.max_linear)
    twist.angular.z = misc.val_map(axes['rx'], -1, 1, -self.max_angular, self.max_angular)
    self.mecanum_pub.publish(twist)

Acquire Key Information

python
def getKey():
    if os.name == 'nt':
        timeout = 0.1
        startTime = rospy.get_time()
        while(1):
            if msvcrt.kbhit():
                if sys.version_info[0] >= 3:
                    return msvcrt.getch().decode()
                else:
                    return msvcrt.getch()
            elif time.time() - startTime > timeout:
                return ''

    tty.setraw(sys.stdin.fileno())
    rlist, _, _ = select.select([sys.stdin], [], [], 0.1)
    if rlist:
        key = sys.stdin.read(1)
    else:
        key = ''

    termios.tcsetattr(sys.stdin, termios.TCSADRAIN, settings)
    return key
