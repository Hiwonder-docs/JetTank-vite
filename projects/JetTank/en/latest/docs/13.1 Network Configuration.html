13.1 Network Configuration ​

13.1.1 Set AP or STA Mode ​

13.1.1.1 Mode Explanation ​

Two network modes are available.

  1. AP direct connection mode: the development board can launch a WiFi that can be connected by the phone. (But it cannot connect to the external network.)

  2. STA LAN mode: the development board can actively connect to the specific hotspot/ WiFi (can connect to the external network)

JetTank will enter AP direct connection mode by default. But in robots formation games, several robots need to be configured as STA LAN mode that is connect these robots to the same WiFi or hotspot.

13.1.1.2 Configuration Instruction ​

Besides the APP, you can amend the system configuration files to change the network mode. The instruction is as follow. (For how to set the network mode via the APP, please refer to 1. Basic Lesson->Lesson 6 APP Connection)

NOTE

the input command should be case sensitive, and the keyword can be complemented by Tab key.

  1. Start JetTank, then connect it to Nomachine.

  2. Double click on to open the command line terminal.

  3. Enter command and press “Enter” to enter the directory of the configuration file.

cd hiwonder-toolbox/
  1. Enter command and press “Enter” to open the configuration file.
vim hw_wifi.py
  1. Press “i” key to enter the editing mode. Then move to the following lines of code.
python
if __name__ == "__main__":
    sn = get_cpu_serial_number()    # get cpu serial number
    led_setup()
    HW_WIFI_MODE = 1  # 1 means AP mode, 2 means Client Mode
    HW_WIFI_AP_SSID = ''.join(["HW-", sn[0:8]])
    HW_WIFI_STA_SSID = "Hiwonder_5G"
    HW_WIFI_AP_PASSWORD = "hiwonder"
    HW_WIFI_STA_PASSWORD = "hiwonder"
    HW_WIFI_AKM_TYPE = pywifi.const.AKM_TYPE_WPA2PSK
    HW_WIFI_CIPHER_TYPE = pywifi.const.CIPHER_TYPE_CCMP
    HW_WIFI_CHANNEL = 7  # 157 161 149
    HW_WIFI_AP_GATEWAY = "192.168.149.1"
    HW_WIFI_COUNTRY = "US"
    HW_WIFI_FREQ_BAND = 2.4
    HW_WIFI_TIMEOUT = 30
    HW_WIFI_RESET_NOW = False
    HW_WIFI_LED = True
  1. Modify the number behind “HW_WIFI_MODE” as 2. 1 refers to AP direct connection mode, 2 indicates LAN mode and 3 represents direct connection sharing mode.
  1. Then, respectively modify “HW_WIFI_STA_SSID” and “HW_WIFI_STA_PASSWORD” as the name and password of the router WiFi.

NOTE

please select 5G WiFi which has faster transmission. If the normal network works slowly, you change it to 5G WiFi.

  1. After modification, press “ESC” key and input “:wq” to exit editing and save the file.
  1. Lastly, restart the robot. The robot will enter LAN mode after restart. If you want to switch back to direct connection mode, you can edit this configuration files again. Modify the value “HW_WIFI_MODE” as 1, then restart the robot.

13.1.2 Change WiFi and IP ​

13.1.2.1 Preface ​

When there are several robots in the same area, it is recommended to modify the WiFi name and IP to avoid connecting to the wrong WiFi generated by other robots.

13.1.2.2 Operation Steps ​

NOTE

the input command should be case sensitive, and the keyword can be complemented by Tab key.

  1. Start JetTank, then connect it to Nomachine.

  2. Double click on to open the command line terminal.

  3. Enter command and press “Enter” to enter the directory of the configuration file.

cd hiwonder-toolbox/
  1. Enter command and press “Enter” to open the configuration file.
vim hw_wifi.py
  1. Press “i” key to enter the editing mode. Then move to the following lines of code.
python
if __name__ == "__main__":
    sn = get_cpu_serial_number()    # get cpu serial number
    led_setup()
    HW_WIFI_MODE = 1  # 1 means AP mode, 2 means Client Mode
    HW_WIFI_AP_SSID = ''.join(["HW-", sn[0:8]])
    HW_WIFI_STA_SSID = "Hiwonder_5G"
    HW_WIFI_AP_PASSWORD = "hiwonder"
    HW_WIFI_STA_PASSWORD = "hiwonder"
    HW_WIFI_AKM_TYPE = pywifi.const.AKM_TYPE_WPA2PSK
    HW_WIFI_CIPHER_TYPE = pywifi.const.CIPHER_TYPE_CCMP
    HW_WIFI_CHANNEL = 7  # 157 161 149
    HW_WIFI_AP_GATEWAY = "192.168.149.1"
    HW_WIFI_COUNTRY = "US"
    HW_WIFI_FREQ_BAND = 2.4
    HW_WIFI_TIMEOUT = 30
    HW_WIFI_RESET_NOW = False
    HW_WIFI_LED = True
  1. Modify the number behind “HW_WIFI_MODE” as 2. 1 refers to AP direct connection mode, 2 indicates LAN mode and 3 represents direct connection sharing mode.
  1. Then, respectively modify “HW_WIFI_STA_SSID” and “HW_WIFI_STA_PASSWORD” as the name and password of the router WiFi.
  1. Next, change the value of “HW_WIFI_AP_GATEWAY” to set the new IP address. For example, 192.168.149.2
  1. After modification, press “ESC” key and input “:wq” to exit editing and save the file.
  1. Restart the robot, and connect to the corresponding WiFi
  1. Open NoMachine, and input the IP address in the search bar. Click the device searched.
  1. Input username “JetTank” and password “hiwonder”. Then click “Login” to enter the system desktop.
